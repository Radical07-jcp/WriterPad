Thesaurus word list. Line format (Moby Thesaurus format): root,related,related,
The GitHub build tries to replace this file with a trimmed copy of the Moby Thesaurus II
(Grady Ward, public domain, https://www.gutenberg.org/ebooks/3202) using packaging/thesaurus/make_thesaurus.py.
You can also drop in your own list in the same format.
